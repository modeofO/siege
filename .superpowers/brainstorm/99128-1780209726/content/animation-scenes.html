Animation Scenes — What Gets Built

Six scenes covering the full battle arc, all driven by anime.js timelines

SCENE 1 Troop March & Deploy

Troops start massed at their base, then march in formation to assigned positions (gates, nodes, repair). This replaces the current instant CSS transition.

BEFORE
×10 all →
AFTER (animated over ~800ms)
×3 atk
×2 def
×2 node
×1 heal
anime.js: Staggered timeline — each troop group departs base with delay, follows eased path to destination. Formation offsets applied with spring easing.
SCENE 2 Gate Clash & Impact

Attackers charge into defenders at each gate. On impact: screen shake, flash burst, damage numbers fly out, defeated troops fade and fall.

TIMELINE
0ms charge
300ms impact
450ms flash+shake
600ms dmg numbers
800ms casualties fade
anime.js: Orchestrated timeline — charge (translateX spring), impact shake (container transform), radial flash (scale+opacity), staggered damage floaters, defeated troops fall with gravity easing.
SCENE 3 Full Round Resolution

The big one — chains scenes 1+2 together with node contests, trap triggers, repair pulses, and vault HP drain into a single cinematic sequence.

0ms Deploy → 800ms Clash → 1400ms Nodes → 1800ms Traps → 2200ms Abilities → 2800ms Repair → 3200ms Vault HP → 3800ms Retreat
anime.js: Master timeline composing sub-timelines. Total ~4s. Each phase is its own timeline added at an offset. This is where anime.js really shines — impossible to orchestrate this with CSS alone.

SCENE 5 Vault Breach (Match End)

When a vault hits 0 HP — dramatic crumble, screen flash, slow-motion final blow, victory/defeat banner.

anime.js: Slow-mo timeline (playbackRate 0.3), camera shake, vault opacity crumble, gold burst particles for winner, red fade for loser.
SCENE 6 Vault HP Drain

Animated HP bar that ticks down with impact — bar shrinks, number counts down, color shifts green → yellow → red, screen edge pulses red at low HP.

anime.js: Value animation (50 → 38), color interpolation via timeline, conditional red pulse overlay when HP < 15.

These are the six scenes. The sandbox lets you trigger and tune each one independently, then Scene 3 composes them all into the full round resolution.
