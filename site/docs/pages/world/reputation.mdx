# Reputation

Reputation is updated during staked-match settlement.

Tracked fields:

- Total losses.
- Current streak.
- Best streak.
- Bracket.

Wins live on `PlayerKingdom.total_wins`; losses live on `PlayerReputation.total_losses`.

## Brackets

The contract calculates brackets from total games and win rate. You land in the highest bracket you qualify for.

| Bracket  | Requirement                        |
| -------- | ---------------------------------- |
| Unranked | Fewer than 10 games.               |
| Bronze   | 10+ games.                         |
| Silver   | 30+ games and win rate above 40%.  |
| Gold     | 60+ games and win rate above 50%.  |
| Diamond  | 100+ games and win rate above 55%. |

Reputation is public world state. It does not replace tier; tier is based on cumulative wins and explicit upgrades.
