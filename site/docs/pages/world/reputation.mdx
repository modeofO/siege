# Reputation

Reputation is updated during staked-match settlement.

Tracked fields:

- Total losses.
- Current streak.
- Best streak.
- Bracket.

Wins live on `PlayerKingdom.total_wins`; losses live on `PlayerReputation.total_losses`.

## Brackets

The contract calculates brackets from total games and win rate.

| Bracket  | Rule                                     |
| -------- | ---------------------------------------- |
| Unranked | Fewer than 10 games.                     |
| Bronze   | 10+ games and below higher thresholds.   |
| Silver   | 30+ games and win rate above threshold.  |
| Gold     | 60+ games and win rate above threshold.  |
| Diamond  | 100+ games and win rate above threshold. |

The exact threshold logic is in `calculate_bracket` in `world_system.cairo`.

Reputation is public world state. It does not replace tier; tier is based on cumulative wins and explicit upgrades.
