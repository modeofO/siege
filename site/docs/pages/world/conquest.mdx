# Conquest

Conquest attacks a neighbor's non-home parcel without starting a full commit-reveal match.

## Preset defense

Defenders call `set_preset_defense(index, p0, p1, p2, g0, g1, g2)`.

Rules:

- Defender preset budget is 12.
- Preset count is limited by tier: 1, 2, 3, then 4.
- Each preset stores three attack and three defense values.

## Attack

`initiate_conquest(target_parcel, p0, p1, p2, g0, g1, g2, ability_id, ability_target)` resolves in one transaction.

Rules:

- Attacker budget is 10.
- Attacker HP is 10.
- Defender HP is 15.
- Target must be owned, non-home, not your own, and adjacent to your territory.
- You cannot conquest a faction ally.
- Ties go to the defender.

If the defender has faction reinforcement enabled, up to three adjacent faction allies can add preset defenses to the random preset pool.

If `ability_id` is non-zero, the contract checks that the attacker owns the ability token and transfers one copy from the attacker to the conquest contract before resolving. Current Cairo does not return that token after resolution, so conquest ability use behaves as a token lock/consume path and requires ERC-1155 operator approval for the conquest contract.

On attacker win, the target transfers to the attacker. On attacker loss, one attacker non-home parcel transfers to the defender if available.

Numeric ability effects are doubled while the world is folded.
