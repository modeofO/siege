# Gate modifiers

Each round, every gate independently rolls a modifier through Cartridge vRNG. Both players see the modifiers before allocating.

Normal is most common. The other four modifiers change how attack and defense resolve for that gate only.

## Reflection detail

Reflection stores overflow damage at the reflected gate. Half of that overflow, using integer division, is applied to each other non-deadlock gate and reduced by unused defense at the receiving gate.
