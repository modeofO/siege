# Resource nodes

Each match has three resource nodes.

| Node   | Contest field | Rewards       |
| ------ | ------------- | ------------- |
| Forge  | `nc0`         | IRON + LINEN  |
| Quarry | `nc1`         | STONE + WOOD  |
| Grove  | `nc2`         | EMBER + SEEDS |

Both players can spend budget contesting a node. Higher contest wins. A tie leaves the previous owner unchanged.

Node contests resolve before gate damage, so owned nodes matter three ways:

- They grant +1 defense at the matching gate (Forge -> gate 0, Quarry -> gate 1, Grove -> gate 2) in the same round you capture or hold them.
- They mint 1 of each paired token to the owner after resolution.
- They add +1 budget next round.

Node ownership starts empty at match creation.
