# Resources

Siege uses six 0-decimal ERC-20 resource tokens.

| Source | Tokens        |
| ------ | ------------- |
| Forge  | IRON + LINEN  |
| Quarry | STONE + WOOD  |
| Grove  | EMBER + SEEDS |

Battle nodes mint resources during match resolution. The Marches also mints resources through Hold drip and pillage drip.

Resources are spent on:

- Crafting T1 abilities.
- Crafting T2 abilities.
- Upgrading Hold tier.
- Creating factions.

Because the tokens are ERC-20s, balances live outside a single match.
