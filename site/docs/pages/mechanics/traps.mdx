# Traps

Traps are hidden one-round defenses placed on resource nodes you already own.

Rules:

- Each trap costs 2 budget.
- Trap values must be 0 or 1.
- You can only trap a node you own at reveal time.
- Trap data is hidden in the commitment and revealed with the rest of your move.
- If the opponent takes a trapped node, they take 5 vault damage.
- Trap damage happens after repair and cannot be repaired in the same round.

Traps last for one round. They must be placed again if you want them in a later round.
