# Siege

Siege is a 1v1 strategy game on Starknet. You fight through three gates, defend your own vault, contest resource nodes, place traps, and spend crafted abilities when a round matters.

The Marches adds the persistent world: Holds, parcel ownership, staked matches, conquest, pillage, factions, and reputation.

## Current note

The Marches is a hex grid of parcels. Each parcel has a position, a type (Forge, Quarry, or Grove), and an owner.
