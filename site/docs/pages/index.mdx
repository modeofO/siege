# Siege

Siege is a 1v1 strategy game on Starknet. You fight through three gates, defend your own vault, contest resource nodes, place traps, and spend crafted abilities when a round matters.

The Marches adds the persistent world: Holds, tile ownership, staked matches, conquest, pillage, factions, reputation, and world folds.

## Current note

The Marches is a tile graph, not a hex grid. Some older writeups still mention hexes; the current game uses square/rhombus tiles, adjacency edges, sectors, zones, and fold state.
