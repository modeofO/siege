# Connect your wallet

Siege runs on two networks:

- **Starknet mainnet** at [www.siegedojo.world](https://www.siegedojo.world) — the real game, where matches have entry buy-ins and ability wagers.
- **Practice** at [siege-dev.vercel.app](https://siege-dev.vercel.app) — a free network for learning the game with nothing at stake.

Both use an in-app network switcher, so you can move between them from either site.

## Cartridge Controller

Both networks use Cartridge Controller. The first connection creates a session and shows a consent screen listing exactly what the session may do: creating matches, committing, revealing, resolving, crafting, staking, claiming drip, conquest, pillage, factions, cosmetics, and approvals.

If the app adds a new session policy after you connected, disconnect and reconnect. Existing sessions keep the policy set they had when they were created.

## Transactions

Gameplay transactions are sponsored — you do not pay gas. Actions are submitted through the Controller session without a signing prompt. If a transaction opens a review sheet, the action is probably missing from the current session policy or your session was created before that policy existed.
