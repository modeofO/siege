# Connect your wallet

Siege has two frontend account modes.

## Sepolia

Sepolia uses Cartridge Controller. The first connection creates a session with policies for common gameplay actions: creating matches, committing, revealing, resolving, crafting, staking, claiming drip, conquest, pillage, factions, cosmetics, and approvals.

If the app adds a new session policy after you connected, disconnect and reconnect. Existing sessions keep the policy set they had when they were created.

## Local dev

Local development uses hardcoded Katana accounts. In dev mode, the app shows an account selector instead of Cartridge.

## Transactions

Most Sepolia actions are submitted through the Controller session. If a transaction opens a review sheet, the action is probably missing from the current session policy or your session was created before that policy existed.
