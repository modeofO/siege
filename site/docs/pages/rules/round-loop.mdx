# The round loop

_The war is long. The round is short. Everything interesting happens in between._

A single round has six stages. Every match repeats this loop until one vault falls.

## 1. Modifier roll

Each of the **3 gates** independently rolls one modifier via Cartridge vRNG. All three rolls happen on-chain before allocation begins, and both players see the results before they plan. A gate might be Normal, Narrow Pass, Mirror Gate, Deadlock, or Reflection — see [Modifiers](/mechanics/modifiers) for the full effects.

## 2. Allocation

Each player privately fills in their **13-slot allocation** from their shared budget. This is the core decision of the round: attack, defense, repair, node contests, and traps, all competing for the same pool of points. See [Budget allocation](/rules/budget) for the slot layout.

## 3. Commit

Each player picks a random salt, computes a Poseidon hash of `[salt, ...allocation]`, and submits only the **hash** to the contract. The opponent sees the hash but not the allocation. See [Commit & reveal](/rules/commit-reveal) for why this matters.

## 4. Reveal

Once both players have committed, each reveals their full allocation plus their salt. The contract recomputes the hash and verifies it matches the commitment. If the numbers don't match the hash, the reveal fails and the round's actions are forfeited.

## 5. Resolution

Everything happens on-chain in one pass:

- Damage is computed gate-by-gate with modifiers applied.
- Repair is applied after damage.
- Node contests are resolved and resource tokens are minted to the winners.
- Traps fire if an opponent stepped into a trapped node.
- Abilities take effect.
- Vault HPs update.

See [Scoring & damage](/rules/scoring) for the math.

## 6. Loop or end

If both vaults are alive, the next round begins with a fresh modifier roll. If either vault is at 0, the match is over.

A complete match is typically **3–6 rounds**.
