# The round loop

Every round has three phases.

## 1. Commit

Each player submits a Poseidon hash of their allocation and a random salt. The allocation stays hidden.

## 2. Reveal

After both commits are in, each player reveals the salt and allocation. The contract recomputes the hash and rejects mismatches.

Reveal data includes attack, defense, repair, node contests, traps, ability id, and ability target.

## 3. Resolve

After both reveals are in, anyone can resolve the round. Resolution applies:

- Gate modifiers.
- Ability effects.
- Repair.
- Gate damage.
- Direct vault damage.
- Node contests.
- Trap damage.
- Resource rewards.
- Win or next-round state.

Commit and reveal deadlines are 300 seconds each. Timeout handling exists for stalled rounds.
