# Commit & reveal

Siege uses commit-reveal so neither player can wait to see the other's move before choosing their own.

## Commit hash

The 1v1 reveal hash order is:

```text
salt, p0, p1, p2, g0, g1, g2, repair, nc0, nc1, nc2, trap0, trap1, trap2, ability_id, ability_target
```

The salt is random. The rest is the allocation that will later be revealed.

## Reveal checks

On reveal, the contract checks:

- The match is active.
- Both players committed before revealing.
- The caller is in the match.
- The commitment exists and has not already been revealed.
- The Poseidon hash matches.
- Total spend is within budget.
- Trap values are 0 or 1.
- Traps are only placed on nodes the player owns.
- The ability id is valid and available in the player's staked match abilities.

An ability token can be activated once per match.
