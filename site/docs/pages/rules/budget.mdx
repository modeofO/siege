# Budget allocation

Your round budget is:

```text
10 + number of resource nodes you control
```

The maximum is 13.

## Spend categories

| Field                     | Meaning                                         |
| ------------------------- | ----------------------------------------------- |
| `p0`, `p1`, `p2`          | Attack pressure at gates 0, 1, and 2.           |
| `g0`, `g1`, `g2`          | Defense at gates 0, 1, and 2.                   |
| `repair`                  | Vault healing, capped at 3 during resolution.   |
| `nc0`, `nc1`, `nc2`       | Contest values for Forge, Quarry, and Grove.    |
| `trap0`, `trap1`, `trap2` | Hidden traps on owned nodes. Each trap costs 2. |

The contract rejects reveals that spend over budget.

## Ability fields

Ability activation is not part of the numeric budget. You may reveal `ability_id = 0` for no ability, or an available staked ability token ID from 1 to 10. `ability_target` is a gate index from 0 to 2 and matters for Siege Sword.
