# Goal & win condition

Your goal is to reduce the opponent's vault to 0 before yours falls.

Each 1v1 match starts with:

- Player A vault: 50 HP.
- Player B vault: 50 HP.
- Round: 1.
- Three unowned resource nodes.

The match ends when either vault reaches 0. If both vaults reach 0 in the same round, the result is a draw. If no vault falls by round 10, the higher HP wins. Equal HP at the round limit is a draw.

In a staked match, the result also determines ability stakes, reputation changes, parcel claim rights, and possible pillage eligibility.
