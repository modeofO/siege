# Repository Docs

This directory contains historical design specs, implementation plans, and art notes.

Where to look:

- `../README.md`: current project overview and deployment notes.
- `../frontend/README.md`: current frontend setup.
- `../mcp-server-2/README.md`: current MCP server setup and tools.
- `../site/docs/pages/`: current player-facing rules.
- `superpowers/specs/` and `superpowers/plans/`: dated design records. They explain why features were built but may not match current code.
- `blender-style-guide.md`: art-direction notes.

When a dated plan conflicts with Cairo, TypeScript, manifests, or config, treat the code as authoritative.
